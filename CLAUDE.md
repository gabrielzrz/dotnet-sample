# CLAUDE.md

This file provides guidance to Claude Code when working in this repository.

## Project overview

This is a **learning project** — a **Web API** built with .NET. Its purpose
is to explore and practice .NET development, so clarity and learning value
matter more than production polish.

## Tech stack

- **.NET 10**

## Endpoints

Either approach is acceptable for building endpoints — choose whichever fits
the situation:

- **Controllers**
- **Minimal APIs**

## Important rules

- **Never commit code automatically.** Do not run `git commit` (or push)
  on your own. Leave committing to the user unless explicitly asked to
  commit in a specific request.
- **When explaining a programming concept, reference the Java/Spring
  equivalent.** Draw a comparison to how it works in Java with Spring to
  help ground the explanation.
